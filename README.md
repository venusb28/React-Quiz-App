# Frontend Quiz App

A React + Vite multiple-choice quiz application made to match the supplied activity.

## Run it
1. Extract this ZIP.
2. Open the extracted `quiz-app` folder in VS Code.
3. Open the terminal in that folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the Local URL shown in the terminal (usually http://localhost:5173).

## Included
- Home, Quiz, and Results routes using React Router
- 10 multiple-choice questions stored in an array of objects
- Four answer choices per question
- Question navigation, selected-answer state, progress bar, and score calculation
- Results with total, correct, incorrect, final score, and percentage
- Retake Quiz and Return Home buttons
- Reusable QuestionCard, AnswerOption, QuizHeader, ProgressBar, and ResultCard components
- Responsive CSS
